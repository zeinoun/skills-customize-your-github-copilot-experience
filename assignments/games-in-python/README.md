
# 🎮 Hangman Game Challenge

## 🎯 Objective

Build a Hangman word-guessing game in Python that uses strings, loops, conditionals, and user input.

## 📝 Tasks

### 🛠️ Game Logic

#### Description

Create the core Hangman gameplay so the program selects a random word and updates the display after each guess.

#### Requirements
Completed program should:

- Choose a random word from a predefined list
- Accept one letter per guess from the player
- Reveal correctly guessed letters in the word display
- Keep track of and show remaining incorrect guess attempts
- End the game when the player guesses the word or runs out of attempts

### 🛠️ Player Feedback

#### Description

Display progress, wrong guesses, and a final win or lose message to the player.

#### Requirements
Completed program should:

- Show the current word progress in `_ _ _` format
- Display letters that were guessed incorrectly
- Notify the player when they win or lose
- Keep the user experience clear and easy to follow
